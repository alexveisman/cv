Подчёркнутые слова есть в словаре — нажми, чтобы увидеть перевод. Кнопка ▶ читает строку вслух (если в устройстве есть голос иврита).

Нажми на статус, чтобы переключить: новое → учу → знаю.

Нажми на карточку, чтобы перевернуть. «Помню» два раза подряд — слово переходит в «знаю». Клавиши: пробел — перевернуть, ← не помню, → помню.

Как добавить новый текст

  1. Сфотографируй страницы учебника.
  2. Отправь фото Claude вместе с промптом ниже (кнопка копирует его).
  3. Claude ответит блоком JSON. Вставь его в поле и нажми «Добавить».

Вставь JSON нового текста

Добавленные тексты хранятся только в этом браузере. Чтобы текст остался навсегда и был на всех устройствах, его кладут файлом в папку hebrew/texts/ репозитория.
