# Ульпан-тетрадь

Тренажёр для текстов на иврите: текст по предложениям (иврит · транслитерация · перевод), словарь, карточки.

## Как открыть
Открой `index.html` в браузере (двойной клик по файлу). Ничего устанавливать не нужно.

## Что внутри
```
hebrew/
  index.html        приложение: вкладки «Текст», «Слова», «Карточки», «Добавить текст»
  texts/tzabar.js   данные одного текста (каждый текст — отдельный файл)
```

## Как добавить новый текст
**Быстро (только в этом браузере):** вкладка «Добавить текст» → скопируй промпт → отправь его Claude с фото страниц → вставь ответ (JSON) → «Добавить».

**Навсегда (в репозиторий):**
1. Создай `texts/<имя>.js` по образцу `tzabar.js`:
   `(window.HEB_TEXTS = window.HEB_TEXTS || []).push({ ...JSON текста... });`
2. Добавь в `index.html` рядом со строкой `<script src="texts/tzabar.js"></script>` такую же строку для нового файла.

## Формат текста
| поле | что это |
|---|---|
| `id` | короткое имя латиницей |
| `title`, `titleRu` | заголовок на иврите и по-русски |
| `sections[].lines[]` | `he` — предложение, `tr` — транслитерация, `ru` — перевод, `note` — пояснение (необязательно) |
| `vocab[]` | `he`, `tr`, `ru`, `root` (корень), `note`, `forms` — формы слова, как они стоят в тексте (без приставок ו ה ב ל מ ש כ), чтобы слово подсвечивалось |

Транслитерация кириллицей; ударение — знак ́ над гласной; `h` — звук ה.

Прогресс (какие слова «знаю») хранится в браузере (localStorage), на другом устройстве он свой.
