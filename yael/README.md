# Тренажёр יע״ל

Тренажёр для подготовки к тесту на знание иврита (יע״ל, NITE). Опубликован как Artifact на claude.ai,
исходник лежит здесь.

**Живая версия:** https://claude.ai/artifact/MnPo8knQhCr4JtJYN4v1N2

## Что внутри

| Вкладка | Что делает |
|---|---|
| **Главная** | Как устроен тест, стратегия на время, ваши цифры. |
| **Тренировка** | Блоки по 10 вопросов: дополнение предложений, перефразирование, текст с вопросами, смешанный, «мои ошибки». Сразу показывает ответ и объяснение по-русски. Кнопка «Разобрать подробнее с Claude». Claude также может сгенерировать новые вопросы. |
| **Экзамен** | 2 раздела по 22 вопроса × 20 минут, лист ответов с кружками, затем сочинение 15 минут. В конце балл по шкале 50–150. |
| **Сочинение** | Тема, таймер, тетрадные линейки. Claude ставит 1–7 по четырём критериям NITE, исправляет ошибки и показывает улучшенную версию. |
| **Связки** | 48 карточек (אלא, אמנם, שכן, לולא, בעוד…) с переводом и примерами. |
| **Прогресс** | Точность по типам и темам, история экзаменов. |

## Откуда что взято

- **Структура теста, критерии сочинения, таблица перевода баллов и проценты сдающих** взяты из материалов
  NITE: буклет «מועד אביב 2021 להתנסות» и русская брошюра с примерами.
- **Все вопросы, тексты и темы сочинений написаны для этого тренажёра.** Официальные вопросы NITE
  сюда не скопированы: на каждой их странице стоит запрет копировать и распространять. Их стоит решать
  в оригинальных PDF с сайта nite.org.il.
- Перевод оценки сочинения (1–7) в шкалу 50–150 сделан грубо, по прямой. Официальной формулы NITE не публикует.

## Как устроено технически

Один HTML-файл без сборки. Три способности claude.ai через `window.claude.use(...)`:

- **`user` + `db`**: прогресс лежит в `data/users/<ваш id>/` (документы `progress`, `essays`, `generated`).
  Этот путь приватный: даже если поделиться ссылкой, каждый видит только свой прогресс.
- **`sample`**: запросы к Claude со страницы (разбор вопроса, генерация вопросов, проверка сочинения).
  Расходуется лимит того, кто открыл страницу.

Если способность недоступна, страница всё равно работает: прогресс сохраняется в `localStorage`,
а ИИ-кнопки скрываются.

## Как вносить изменения

1. Правите `yael/index.html` (банк вопросов — массивы `SC`, `RS`, `RC`, `TOPICS`, `LINKS` в начале скрипта).
2. Просите Claude Code опубликовать этот же путь — артефакт обновится по той же ссылке, прогресс не потеряется.
3. Коммитите и пушите.
