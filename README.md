# Israel PM Pipeline

Инструмент для поиска работы Growth PM в Израиле. Опубликован как Artifact на claude.ai,
исходник живёт здесь.

**Живая версия:** https://claude.ai/code/artifact/873d4621-7270-4629-bb34-f18daeebc47a

---

## Что он делает

| Вкладка | Задача |
|---|---|
| **Пайплайн** | Канбан откликов: Радар → Отклик → Скрининг HR → Интервью → Финал → Оффер → Отказ. Карточки перетаскиваются мышкой. Помечает вакансии, где дедлайн настал или больше 10 дней тишины. |
| **Радар вакансий** | Строит готовые поисковые ссылки на 11 израильских и международных бордов (LinkedIn, AllJobs, Drushim, JobMaster, Startup Nation, Janglo, Indeed IL, Google Jobs, Glassdoor, Gav-Yam Negev, Wellfound) из твоей роли и города. |
| **Добавить вакансию** | Вставляешь текст вакансии → Claude разбирает его на поля, считает совпадение с профилем (0–100), показывает пробелы и ключевые слова для ATS. |
| **Резюме и письмо** | Cover letter, версия резюме под вакансию, сообщение рекрутеру (EN / עברית / RU), подготовка к интервью. |
| **Аналитика** | Воронка по стадиям, конверсия между ними, разбивка по источникам, список «требует действия», выгрузка в CSV. |
| **Профиль** | Источник правды для всех ИИ-генераций. Заполнен из резюме. |

## Как это устроено технически

Страница — один HTML-файл. Никакого бэкенда, никакой сборки. Три способности, которые
claude.ai выдаёт опубликованной странице через `window.claude.use(...)`:

- **`db`** — хранилище. Коллекция `jobs` (по документу на вакансию), документы `profile/main`
  и `settings/main`. Подписка `onSnapshot` перерисовывает доску, когда данные меняются.
- **`sample`** — обращение к Claude прямо со страницы. Используется для разбора вакансии
  (`sample.json` → строгий JSON) и для генерации документов (`sample` со стримингом текста).
- **`downloads`** — сохранение файлов: CSV пайплайна и .txt сгенерированных писем.

Каждая способность может быть недоступна (например, страницу открыл человек без прав) —
тогда `use()` возвращает `null`. Поэтому весь код написан так, чтобы страница работала и без них:
данные тогда падают в `localStorage`, а ИИ-кнопки прячутся с честной подписью.

### Важное ограничение

Страница **не может сама ходить на LinkedIn или AllJobs**. Браузер режет такие запросы
политикой безопасности (CSP) — это не баг конкретно этого тула, а правило платформы.
Поэтому «агрегация вакансий» реализована честным обходным путём: тул собирает поисковые
ссылки с твоими фильтрами, ты открываешь их в один клик, а найденную вакансию возвращаешь
обратно через «Добавить вакансию» — там Claude разбирает её за тебя.

Настоящий автопоиск потребовал бы отдельного сервиса (например, Python-скрипт на расписании),
который сам ходит по бордам и складывает результат в базу. Это следующий шаг, если понадобится.

## Как вносить изменения

1. Правишь `job-hunt/index.html`.
2. Просишь Claude Code опубликовать этот же путь — артефакт обновится **по той же ссылке**,
   данные в `db` при этом не теряются.
3. Коммитишь и пушишь — репозиторий остаётся историей версий.

Файл специально написан без внешних библиотек: только Google Fonts. Всё остальное — обычные
HTML, CSS и JavaScript, которые можно читать сверху вниз.
